# Content licenses

The application source code is licensed under AGPL-3.0-only. Platform content
uses separate, explicit licenses:

- Explanations and prose: CC BY-SA 4.0
- Scratch code snippets: CC0 1.0
- `.sb3` examples: CC BY 4.0 by default, unless an artifact records another
  license

Each imported or contributed content revision must retain its own attribution
and license metadata in D1. Repository source licensing never overrides content
licensing.
